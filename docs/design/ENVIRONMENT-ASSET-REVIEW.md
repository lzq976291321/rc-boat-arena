## 文件与验收

- Poly Haven 使用官方公开 API 和 1K glTF，96 个源文件全部按官方大小与 MD5 核对；使用既有 `tools/assets/pack-gltf.py` 原样内嵌缓冲与贴图。来源、作者、许可、加工、大小、三角面与 SHA-256 写入每件 `SOURCES.md` 和 catalog。
- 18 件 GLB 头、分块、缓冲视图边界、自包含依赖检查通过；主任务再次独立核对文件大小、SHA-256、内嵌资源与来源文件。
- 在独立构建预览服务 `/library/` 逐件选择 18 件模型，核对选中名称、加载完成状态、实测信息和截图；10 条候选核对暂无模型预览、未下载状态与原始链接。
- 构建、`check:bundle` 和 `check:routes` 通过。预览服务期间没有项目页面运行错误。
- 独立视觉复核：树根和树桩带扫描土壤底片，须埋入岸土；低矮灌丛 04 的四株共一个网格，须拆分几何后才能独立摆放；中型枯枝组合是三根分开的枝条。
- 木框提灯只提供模型与玻璃，场景发光需另行实现；草灌保留双面 MASK 叶片，实际批量摆放仍需检查密度、透明遮挡和性能。
