## 筛选结论

- 木码头：推荐优先应用。木板、支撑、绳索及做旧细节完整，7 个网格保留完整模块展示排布。场景中应选择需要的段落，并设置支柱入水深度和避让区域。
- 黄铜提灯：推荐搭配码头或船屋。33,902 三角面适合少量近景装饰，带黄铜与玻璃材质。实际夜间照明需要另加光源，不能把有提灯模型等同于具备场景照明。
- 航标浮标：适合航道入口与转弯标记。锈蚀、剥落涂层、铃铛、灯罩和底部附着物可见；入水、浮动和发光强度须在场景中适配。
- 救生圈：适合挂在码头或船屋。绳索、磨损、反光带与文字贴图完整；需按实际尺度挂载。

## 文件与预览验收

通过官方公开 API 取得文件清单，逐文件按官方 MD5 校验。`tools/assets/pack-gltf.py` 将 glTF 外部缓冲区和图片字节原样打包为自包含 GLB，不改几何、材质、节点与贴图。另逐段比较打包前后缓冲区与图片，确认没有丢失或变更。

四款已在项目素材库中逐一加载并查看实际渲染，未发现项目控制台错误。源文件与 API 元数据保存在仓库外；发布文件、作者、来源、许可、SHA-256 和接入备注写入资产清单与各素材目录 SOURCES.md。
