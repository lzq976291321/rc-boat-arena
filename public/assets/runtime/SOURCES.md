## 当前加工规则

四艘船（Riva Aquarama、MAVERICK GT、Motor Whaleboat、Assault Boat）均保留完整所用几何、节点、UV 和材质分区，不进行船体减面；运行贴图最长边为 512，透明通道保留。船首方向、观赏尺寸、吃水和船水接触参数由 `src/scene-assets/sunny-cove/config/boats.js` 配置；各船的运行时材质处理见 [晴湾组合记录](../cove/SOURCES.md)。Motor Whaleboat 与 Assault Boat 由 `tools/assets/build-cove-boats.mjs` 从保留的完整库文件生成。

码头仅保留实际使用的 `modular_wooden_pier_planks` 节点与依赖，共 5,512 面；完整套件仍在原件中。旧轮胎、木桶、黄铜灯保留各自完整所用几何，木桶提手与铜灯玻璃节点均保留。码头、长凳、木箱、救生圈、岸石、岩壁和新增道具的运行贴图最长边均为 256。提灯材质在场景中分别处理铜和玻璃，不对铜使用透射效果。

Shrub 03 选择 `shrub_03_a` 单株（2,385 面），酢浆草选择 `shrub_sorrel_01_d` 单株（990 面）；两者纹理最长边 256，保留所选单株拓扑。Shrub 04 保留完整网格拓扑，共 27,327 面，纹理最长边 512；运行场景再沿株间空隙选择两株完整灌木，不使用整排展示套组。

Jacaranda 当前保留叶冠与主干，剔除不用的细枝部件与对应纹理，并进行带法线、UV 权重的几何减面：叶冠从 288,292 面降至 34,595 面，主干从 46,022 面降至 46,016 面，共 **80,611 面**。六张纹理最长边缩为 **384**；当前交付文件为 **2,036,196 字节**。树冠总体轮廓与支撑主枝已经同机位正反面及场景核对，但细小叶片细节会减少；不将该派生文件描述为几何无损或保留全部源三角面。

2026-10-22 第一轮：17 个运行文件在不改变三角形拓扑和顶点位置的前提下做传输优化。不透明纹理优先重新编码为 AVIF 4:4:4，透明纹理使用 WebP（alpha 以 lossless 方式保存），颜色图 PSNR 不低于 36 dB、法线/ORM 等数据图不低于 38 dB，达不到阈值的贴图保留原 JPEG/PNG；同时移除材质未引用的 TANGENT 和非 0 号 UV 集。运行文件合计由 9,637,908 字节降至 7,672,480 字节，贴图字节由 3,434,278 降至 1,899,165。AVIF/WebP 通过 `EXT_texture_avif`、`EXT_texture_webp` 声明，需要支持对应格式的浏览器；不支持时会缺少贴图，不再内嵌 JPEG 回退副本。

2026-10-22 第二轮：对占比最大的蓝花楹和两个小件做额外减面，未删除任何模型。蓝花楹叶冠由 57,658 面降至 34,595 面（总 80,611 面，相对误差 0.00365），六张纹理上限由 512 降至 384；提灯由 33,902 面降至 16,950 面，灌木 shrub-04 由 27,327 面降至 13,639 面，均改为 16 位索引。运行文件合计进一步降到 **6,448,212 字节**（较原始 -33.1%），贴图字节降到 1,689,913。减面使用法线/UV 权重与误差上限，保留主干、冠形和材质槽；同机位截图已核对，叶缘细节会减少。

所有运行派生文件最后经过有界 FLOAT 精度处理和 Meshopt 压缩，并由 Three.js 所用解码器回读验证。该压缩阶段的位置分量误差上限为 0.0002 个源模型单位，法线/切线分量为 0.001，UV 分量为 1/4096；FLOAT 属性仍为 FLOAT。Meshopt TRIANGLES 可能循环旋转单个三角形的首顶点，但保持压缩输入的三角形顶点集合、顺序和绕向。**这些压缩误差及拓扑校验针对压缩输入，不包括 Jacaranda 前置减面的几何变化，也不表示贴图降采样无损。** Jacaranda 的减面参数与测得相对误差独立记录于清单 `simplification` 字段。

## 重建与校验

新增两艘船使用 `tools/assets/build-cove-boats.mjs`；码头新增道具、三种灌木及当前 Jacaranda 使用 `tools/assets/build-cove-dressing.mjs`。2026-10-22 的纹理再编码使用 `tools/assets/optimize-cove-runtime.mjs`：先由 `decompress-glb.mjs` 展开 Meshopt 数据，再由 `prepare-startup-glb.py --avif --webp --drop-unused-attributes` 处理并重新压缩，审查后由 `publish-cove-runtime.mjs` 复制运行文件并同步清单。脚本生成候选到不发布的 `tools/local/`，不覆盖完整库原件。Python 需安装带 AVIF/WebP 支持的 Pillow；下列 Python 路径为示例占位，应替换为本机对应解释器。

```sh
node tools/assets/build-cove-boats.mjs --python /path/to/python-with-pillow
node tools/assets/build-cove-dressing.mjs --python /path/to/python-with-pillow
node tools/assets/optimize-cove-runtime.mjs --python /path/to/python-with-pillow
node tools/assets/publish-cove-runtime.mjs
pnpm check:delivery
```

当前细节资源验收记录为仓库内 `artifacts/sunny-cove/2026-10-13/single-scene/dressing-delivery.json`；Jacaranda 已重建并确认与经审查运行文件字节完全一致。来源与许可仍以各素材完整来源记录为准，组合及派生加工不改变原许可。
